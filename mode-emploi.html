1. Présentation

Courrier Adrien est un client mail pour Windows qui gère plusieurs comptes à la fois (IMAP : Gmail, Orange, Free, o2switch… et Outlook / Hotmail). Il n'a aucun menu déroulant : chaque fonction est un bouton visible, accessible en un ou deux clics.

En plus de la messagerie, il réunit dans une seule fenêtre : un navigateur intégré, un logiciel de mailing, un lecteur de flux RSS qui les envoie en mails, des macros, des modèles, des rappels (TODO), un carnet d'adresses, l'envoi de SMS et l'affichage de l'écran d'un téléphone Android.

Tout est stocké sur votre ordinateur. Rien n'est envoyé ailleurs qu'à votre fournisseur de messagerie, sauf si vous choisissez vous-même la correction ou la traduction en ligne par Claude (voir section 12).

Licence : PolyForm Noncommercial 1.0.0, usage non commercial. Le texte complet est dans le bouton À PROPOS.

2. Installation et premier lancement

  1. Décompressez tout le dossier où vous voulez (Bureau, Documents…). Ne déplacez pas COURRIER ADRIEN.exe seul : il a besoin du dossier _internal placé à côté de lui.
  2. Double-cliquez sur COURRIER ADRIEN.exe.
  3. Si Windows affiche « Windows a protégé votre ordinateur » (SmartScreen), cliquez sur Informations complémentaires, puis sur Exécuter quand même. Ce message apparaît parce que le programme n'est pas signé numériquement. Certains antivirus peuvent aussi le signaler à tort.

Ajouter votre premier compte

Au premier lancement, la fenêtre COMPTES s'ouvre toute seule :

  1. Ajoutez votre ou vos comptes : voir section 4.
  2. Supprimez ensuite le compte d'exemple « A CONFIGURER ».

Courrier Adrien comme messagerie par défaut

Le bouton DÉFAUT, en bas à droite, propose Courrier Adrien à Windows comme application de messagerie par défaut. Windows ouvre ensuite ses propres réglages pour que vous confirmiez ce choix.

4. Vos comptes : la fenêtre COMPTES

Le bouton COMPTES ouvre la fenêtre où vous ajoutez, modifiez et classez vos comptes de messagerie. Au premier lancement, elle s'ouvre toute seule.

Ajouter un compte

  1. Choisissez votre fournisseur dans la liste : les serveurs et les ports sont préremplis. S'il n'y figure pas, choisissez Autre (manuel) et remplissez vous-même les serveurs IMAP et SMTP et leurs ports (indiqués par votre fournisseur).
  2. Saisissez le Nom (celui qui s'affichera dans la colonne de gauche), l'Adresse et le Mot de passe.
  3. Cliquez sur Ajouter. Un message vert confirme l'ajout.
  • Pour un compte Outlook / Hotmail, utilisez Se connecter avec Microsoft à la place du mot de passe : la connexion se fait sur la page de Microsoft, sans donner votre mot de passe à Courrier Adrien.
  • Certains fournisseurs demandent une étape préalable sur leur site (accès IMAP à activer, mot de passe particulier…) : voir section 5.

Modifier, supprimer, classer

  • Modifier : sélectionnez le compte dans la liste « Comptes configurés », changez ce qui doit l'être, puis cliquez sur Modifier.
  • Supprimer : sélectionnez le compte, puis cliquez sur Supprimer.
  • ▲ Monter / ▼ Descendre : changent l'ordre des comptes dans la colonne de gauche de l'interface générale.

Mise à jour des comptes

Compare chaque dossier de chaque compte avec le serveur : les mails manquants sont téléchargés, et ceux présents seulement sur votre ordinateur sont renvoyés sur le serveur. Aucun mail n'est supprimé. Cela peut prendre plusieurs minutes : c'est normal, et ce n'est à faire qu'exceptionnellement.

5. Réglages particuliers selon votre fournisseur

Pour ajouter un compte, il suffit en général de choisir votre fournisseur dans la liste de COMPTES : les serveurs et les ports sont préremplis. Certains fournisseurs demandent toutefois une étape préalable, de votre côté, sur leur site. Courrier Adrien vous la rappelle d'ailleurs par une ligne d'aide quand vous choisissez ce fournisseur.

Caramail et GMX

Caramail est aujourd'hui géré par GMX : les réglages sont les mêmes pour les deux.

  • Activez d'abord l'accès IMAP sur le site de votre messagerie : E-mail › Paramètres › Fonctions POP3/IMAP › cochez « Envoyer et recevoir des emails via des programmes externes ».
  • D'après GMX, ce réglage se désactive tout seul après une longue période sans utilisation : si votre compte ne fonctionne plus, vérifiez qu'il est toujours coché.
  • Serveurs (préremplis) : IMAP imap.gmx.com, port 993 (SSL) ; SMTP mail.gmx.com, port 587 (STARTTLS).

Gmail

Condition obligatoire pour Gmail

Il vous faut utiliser la validation en deux étapes sur votre compte Google.
Et ensuite utiliser un mot de passe d'application pour Courrier Adrien
Voici le lien direct pour créer ce mot de passe (après vous être connecté et après avoir activé la validation en 2 étapes)
https://myaccount.google.com/apppasswords

  • Le code fait 16 caractères, affichés en 4 groupes : saisissez-le sans les espaces dans le champ « Mot de passe » de Courrier Adrien.
  • Si vous changez le mot de passe de votre compte Google, les mots de passe d'application sont annulés : créez-en un nouveau et remettez-le dans Courrier Adrien.
  • Le mot de passe d'application n'est pas disponible si la validation en deux étapes n'utilise que des clés de sécurité, si la Protection avancée est activée, ou pour un compte professionnel ou scolaire (c'est l'organisation qui décide).

Infomaniak (ik.me)

  • Le mot de passe à saisir n'est pas celui de votre compte Infomaniak. Infomaniak le fournit pour une adresse mail et un appareil (cet ordinateur) : sur le site Infomaniak Mail, Paramètres › Appareils › Ajouter un appareil › Mes e-mails, choisissez votre ordinateur, puis cliquez sur « Afficher le mot de passe ».
  • Notez-le : il ne s'affiche qu'une fois. En cas de perte, ajoutez simplement un nouvel appareil pour obtenir un nouveau mot de passe.
  • Pour la même adresse sur un autre ordinateur ou sur un téléphone, Infomaniak vous fournira un autre mot de passe.
  • Serveurs (préremplis) : IMAP et SMTP mail.infomaniak.com, ports 993 (SSL) et 587 (STARTTLS).

o2switch

  • Dans « Serveur IMAP » et « Serveur SMTP », indiquez le nom de votre serveur o2switch (de la forme nomduserveur.o2switch.net), affiché dans votre espace cPanel. Il est propre à chaque client : il ne peut donc pas être prérempli.
  • Le mot de passe est celui de l'adresse mail, créé dans cPanel.
  • Ports (préremplis) : IMAP 993 (SSL), SMTP 465 (SSL).

Yahoo

Condition obligatoire pour Yahoo

Il est conseillé d'utiliser un navigateur et un appareil que vous utilisez habituellement pour éviter les blocages de sécurité (Yahoo précise : un navigateur avec lequel vous êtes connecté à Yahoo depuis plusieurs jours de suite, et pas en navigation privée).

  1. Connectez-vous et accédez directement à la page Sécurité du compte Yahoo.
    https://login.yahoo.com/account/security
  2. Faites défiler la page jusqu'à la section Connexions externes.
  3. Cliquez sur Créer un mot de passe d'application (ou Générer et gérer les mots de passe d'application).
  4. Saisissez le nom Courrier Adrien
  5. Cliquez sur Générer le mot de passe.
  6. Copiez le code qui s'affiche à l'écran, puis collez-le dans le champ "mot de passe" de Courrier Adrien
  7. Cliquez sur Terminé.

6. Comptes et dossiers

La colonne de gauche affiche une barre par compte. Chaque barre sert de boîte de réception : cliquez dessus pour afficher les mails reçus de ce compte. Son arborescence de dossiers s'affiche juste en dessous.

  • Le nombre de mails non lus s'affiche à droite de chaque barre.
  • Le petit rond gris devant le nom d'un compte force la relève immédiate de ce seul compte.
  • Pour ajouter un compte ou changer leur ordre : bouton COMPTES (section 4).
  • Pour renommer un compte, double-cliquez sur son nom (ou appuyez sur F2).

Corbeille et Envoyés : ménage automatique

Pour qu'ils ne grossissent pas indéfiniment, la Corbeille et le dossier des Envoyés de chaque compte peuvent faire leur ménage tout seuls. Juste sous le bandeau du dossier, le réglage Garder fixe le nombre de mails conservés : au-delà, les plus anciens sont supprimés définitivement (aussi sur le serveur) dès que vous validez le réglage, puis à chaque ouverture du dossier.

  • Choisissez TOUT (rien n'est jamais supprimé automatiquement) ou les derniers, puis tapez le nombre de mails à garder, de 50 à 5 000, et validez avec Entrée ou le bouton OK.
  • Si ce nombre entraîne des suppressions, Courrier Adrien vous demande d'abord confirmation.
  • Pendant le ménage, la barre du bas affiche le décompte (« Ménage automatique : 120 / 466 anciens mails supprimés… ») et les mails disparaissent de la liste un par un, puis un bilan s'affiche à la fin.
  • Par défaut : les 300 derniers pour la Corbeille, TOUT pour les Envoyés.
  • Le réglage est propre à chaque Corbeille et à chaque dossier Envoyés de chaque compte, Outlook compris (sa corbeille s'appelle « Éléments supprimés »).
  • Ce sont toujours les mails les plus anciens, par leur date (ceux du bas de la liste), qui partent en premier. Attention : un vieux mail que vous venez de mettre à la Corbeille peut donc être effacé aussitôt.

7. La liste des mails

Chaque mail occupe deux lignes. Les couleurs indiquent son état :

CouleurSignification
doréMail non lu
bléMail sélectionné
ocreSurvol par la souris

Quatre symboles cliquables :

  • à gauche, un triangle (rouge si le mail a des pièces jointes) et un rond qui indique si vous avez répondu ;
  • à droite, une étoile pour épingler le mail, et un petit bonhomme qui retrouve tous les mails de cet expéditeur, quel que soit leur dossier.

Sélection multiple : Maj + clic, Ctrl + clic, ou Ctrl+A. Les flèches ↑ ↓ passent d'un mail à l'autre.

8. Lire un mail

L'en-tête affiche l'expéditeur, le destinataire, la date en toutes lettres et le sujet en gros caractères. Cliquer sur une adresse ouvre le carnet d'adresses pour y ajouter cette personne.

Boutons du bandeau du mail :

  • Les traceurs invisibles insérés dans certaines newsletters (« pixels espions ») ne bloquent pas l'affichage.

9. Pièces jointes

Les pièces jointes s'affichent en haut du mail, avec leur icône, leur nom et leur poids.

  • Un clic ouvre l'aperçu dans la fenêtre du mail : PDF, Word, Excel, OpenDocument, PowerPoint, images et vidéos.
  • Le bouton Plein écran agrandit l'aperçu ; Retour à la page revient au mail.
  • Pour les images et les PDF, les flèches ◀ ▶ passent d'une photo ou d'une page à l'autre. Les touches directionnelles ← → font la même chose.
  • Zoom : boutons + −, ou touches + et − du clavier.
  • La petite flèche à côté d'une pièce jointe l'ouvre avec le logiciel habituel de Windows.
  • Enregistrement : une seule pièce jointe, une sélection (Tout sélectionner / Tout désélectionner) ou toutes à la fois, dans le dossier de votre choix (Parcourir).

10. Écrire un mail

Cliquez sur NOUVEAU, RÉPONDRE (Ctrl+R), RÉP. À TOUS, TRANSFERT ou RENVOYER.

  • Destinataires : les adresses se complètent pendant la frappe. Cliquer sur l'étiquette À, Cc ou Cci ouvre le carnet d'adresses pour choisir les destinataires.
  • Mise en forme : boutons Gras Italique Souligné Barré Couleur Émoticônes Langue, ainsi que la taille de la police.
  • Pièces jointes : elles s'affichent dans une colonne à droite. La petite croix rouge retire une pièce jointe.
  • Accusé de réception : enfoncé, il demande un accusé de lecture au destinataire.

Deux façons d'envoyer

11. Envoi différé (DÉLAI)

Le bouton DÉLAI, en bas de la fenêtre, règle le délai appliqué au bouton Envoyer :

  • 1 minute, 15 minutes ou 30 minutes ;
  • Heure précise, au format HH.MM (par exemple 08.00). Si l'heure est déjà passée, le mail part le lendemain à cette heure-là.

Le délai choisi reste affiché sur le bouton (« DÉLAI 15mn », « DÉLAI 08.00 »…). Les mails en attente sont indiqués dans la barre du bas.

Astuce : un délai d'une minute suffit pour rattraper un mail parti trop vite, une pièce jointe oubliée ou un mauvais destinataire.

12. Orthographe, grammaire, traduction

Orthographe pendant la frappe (gratuit)

Les mots inconnus sont soulignés pendant que vous écrivez. Faites un clic droit sur un mot souligné : les corrections proposées s'affichent en haut du menu. Les dictionnaires français (orthographe classique et réformée de 1990) et anglais sont actifs ensemble. La correction fonctionne aussi dans les champs des sites web ouverts dans Courrier Adrien.

Le bouton « Langue » de la fenêtre de rédaction

Il ouvre une fenêtre de choix : corriger ou traduire, sur cet ordinateur (gratuit) ou avec Claude (en ligne, payant). Seul le texte que vous avez écrit est traité, jamais la citation du mail d'origine. Revenir au texte d'avant annule la dernière correction ou traduction.

Traduire un mail reçu

Le bouton TRADUIRE du bandeau détecte la langue et traduit le mail vers l'autre langue (français ↔ anglais). Si une clé Claude est enregistrée, vous pouvez choisir « Sur cet ordinateur » ou « Avec Claude », qui traduit depuis toutes les langues. Le bouton se remplit de jaune avec le pourcentage d'avancement. Le même bouton existe dans la barre d'adresse des pages web.

Configurer Claude (facultatif)

Dans la fenêtre Langue, cliquez sur Réglages-prix de Claude…. Quatre boutons vous mènent directement aux pages du site platform.claude.com : création du compte, achat de crédit, plafond de dépense et création de la clé. La clé que vous copiez sur le site est collée toute seule au retour dans Courrier Adrien.

  • Modèles : Opus par défaut (environ 2 centimes par mail), Sonnet (environ 1 centime) ou Haiku (moins de 0,1 centime).
  • Tester la clé ne coûte rien. Le coût approximatif s'affiche après chaque opération, et un compteur suit vos dépenses (Remettre le compteur à zéro après un nouvel achat).
  • L'abonnement Claude Pro n'inclut pas ce crédit d'API.
  • La clé est chiffrée par Windows et illisible depuis une autre session Windows.
Confidentialité : avec Claude, le texte concerné est envoyé à Anthropic (États-Unis). Rien n'est envoyé sans une action de votre part. Les outils locaux, eux, ne transmettent rien.

13. Macros et modèles

MACROS

Une macro écrit un texte tout prêt en un clic. Elle ouvre la fenêtre de rédaction comme le bouton choisi (Nouveau mail, Répondre, Répondre à tous, Transférer ou Renvoyer le mail sélectionné), puis insère son contenu à l'emplacement du curseur. L'envoi reste manuel : c'est vous qui cliquez sur Envoyer.

Dans MACROS, créez une macro avec + et choisissez son bouton de départ. Ajoutez ensuite ses étapes (Ajouter) : du texte, un saut de ligne, ou le contenu du presse-papiers au moment du clic. Ordonnez-les (▲ Monter / ▼ Descendre), puis cliquez sur Sauvegarder. Chaque macro devient un bouton dans la barre du bas, à gauche de DÉLAI.

MODÈLES

Les modèles sont définis compte par compte, avec deux types : Nouveau message et Réponse / Transfert. Le modèle est appliqué automatiquement quand vous écrivez depuis ce compte.

  • Outils de l'éditeur : Couleur, Image, Séparateur, et Curseur, qui indique où placer le curseur au début de la rédaction.
  • Image (logo, signature…) : au moment de l'insertion, vous choisissez entre deux options.
    • Image en ligne : collez le lien direct d'une image déjà sur Internet (par exemple la bannière de votre site) ;
    • Image de l'ordinateur : laissez ce champ vide, puis choisissez le fichier. L'image est alors intégrée au modèle.
    Dans les deux cas, vous pouvez ensuite ajouter un lien (facultatif), qui s'ouvrira quand on cliquera sur l'image, par exemple l'adresse de votre site.
  • Dupliquer le modèle nouveau message le recopie dans le modèle de réponse.
  • Copier vers un autre compte reprend le même modèle sur d'autres comptes (cases à cocher).
  • N'oubliez pas de cliquer sur Sauvegarder.

14. Carnet d'adresses

Bouton ADRESSES. Les contacts sont rangés dans des dossiers (Nouveau, Renommer, Supprimer ; F2 pour renommer).

  • Chaque contact peut avoir une adresse mail, un numéro de téléphone, ou les deux. Fiche : nom, mail, téléphone fixe, téléphone portable, autres téléphones (séparés par « ; ») et notes.
  • La recherche fonctionne sur le nom, l'adresse, le numéro (par exemple « 06 12 ») ou les notes.
  • Écrire : nouveau mail aux contacts sélectionnés. SMS : SMS aux contacts sélectionnés, par le téléphone relié.
  • Copier vers… copie des contacts dans un autre dossier. Vous pouvez aussi les faire glisser vers ce dossier en tenant la touche Ctrl.
  • Import / export CSV : les colonnes Téléphone, Mobile ou Portable sont reconnues. Réimporter un fichier complète les contacts déjà présents.
  • Import / export Excel : un onglet par dossier (créé automatiquement s'il n'existe pas), plus un onglet avec tous les contacts à l'export.
  • Importer du tél. : récupère les contacts du téléphone relié (voir la liaison avec le téléphone). Les groupes du téléphone deviennent des dossiers ; les contacts sans groupe vont dans le dossier « Téléphone ». Avant tout enregistrement, un récapitulatif indique combien de contacts seront ajoutés ou complétés : un contact déjà présent n'est pas ajouté une deuxième fois, seuls ses numéros, mail ou notes manquants sont complétés. Rien n'est effacé ni remplacé dans le carnet, et rien n'est modifié sur le téléphone. Vous pouvez recommencer l'import plus tard pour récupérer les nouveaux contacts.
  • Envoyer au tél. : fait l'inverse pour les contacts venus du téléphone. Chacun reste lié à sa fiche du téléphone par une clé invisible : Courrier Adrien y ajoute les numéros, le mail et la note que vous avez saisis dans le carnet et qui manquent sur le téléphone. Rien n'y est remplacé ni supprimé. Si des contacts sont sélectionnés, vous pouvez n'envoyer qu'eux. Un récapitulatif est affiché avant l'envoi ; une sauvegarde de tous les contacts du téléphone est faite dans Courrier Adrien juste avant, et à la fin Défaire ces changements annule la modification que vous venez d'effectuer (après confirmation).
  • Contacts supprimés : un contact venu du téléphone et supprimé ensuite d'un côté peut l'être aussi de l'autre, toujours sur votre accord :
    • supprimé du téléphone : au prochain Importer du tél., Courrier Adrien le signale et propose de le supprimer aussi du carnet (ou de l'y garder) ;
    • supprimé du carnet : il n'est plus réimporté. Au prochain Envoyer au tél., Courrier Adrien propose de le supprimer aussi du téléphone, de l'y garder, ou de décider plus tard. Une sauvegarde des contacts du téléphone est faite avant, et Défaire ces changements recrée les contacts supprimés.
    Un contact copié dans plusieurs dossiers n'est considéré comme supprimé que lorsque sa dernière copie l'est.
  • Restaurer propose de restaurer :
    • le carnet d'adresses : retour à un état précédent du carnet. Une sauvegarde est faite automatiquement avant chaque modification ;
    • les contacts du téléphone : avant chaque envoi vers le téléphone, une sauvegarde de tous ses contacts est faite dans Courrier Adrien (les 10 dernières sont gardées). Choisissez une sauvegarde, puis :
      • Remettre sur le téléphone : y remet ce qui manque par rapport à la sauvegarde (contacts supprimés depuis, numéros, mails ou note effacés). Rien n'y est retiré ni remplacé ; un récapitulatif est affiché avant, et la remise peut être annulée ;
      • Excel ou CSV : enregistre la sauvegarde dans un fichier, lisible par Excel ou réimportable dans le carnet ;
      • vCard (.vcf) : fichier que le téléphone sait importer lui-même (application Contacts), par exemple après une réinitialisation du téléphone.

15. Spam

Sur un mail indésirable, cliquez sur SPAM dans la barre du bas : le mail part dans le dossier spam du compte, et l'expéditeur est ajouté à une liste commune à tous vos comptes. Ses prochains mails iront directement en spam, quel que soit le compte qui les reçoit.

Une erreur ? Ouvrez le mail dans le dossier spam et cliquez sur NON SPAM. Le bouton SPAM de la barre du haut affiche la liste complète des expéditeurs bloqués.

Attention : un mail supprimé depuis un dossier spam est effacé définitivement, sans passer par la corbeille.

Courrier Adrien n'a pas de filtres automatiques (règles de tri).

16. Rechercher et trier

  • RECHERCHER : recherche par expéditeur ou dans les en-têtes. ✕ revient à l'affichage normal.
  • Le petit bonhomme d'un mail (à droite dans la liste) affiche tous les mails de cet expéditeur, avec leur dossier.
  • Le bouton de tri change de mode à chaque clic : CHRONO (par date de réception) ou EXPÉDITEUR (par ordre alphabétique). Le tri choisi est mémorisé pour chaque dossier. Les mails épinglés restent toujours en haut.
  • Dans la Corbeille seulement, un troisième mode apparaît : SUPPRESSION. Il affiche en premier les mails supprimés le plus récemment, pour retrouver vite un mail effacé par erreur, même dans une corbeille de plusieurs centaines de mails.

17. Navigateur intégré et vidéos

Un clic sur un lien d'un mail ouvre la page dans Courrier Adrien, à la place du mail. La barre d'adresse propose :

  • CORPS pour revenir au mail ;
  • COPIER pour copier l'adresse de la page ;
  • INTERNET pour ouvrir la page dans un autre navigateur, choisi dans une liste ;
  • TRADUIRE et PLEIN ÉCRAN.

Si un site refuse de s'afficher dans le panneau intégré, un bouton rouge « ⚠ PAGE BLOQUÉE — OUVRIR EN EXTERNE » l'ouvre dans le navigateur par défaut de Windows.

Le clic droit offre les commandes habituelles : copier l'adresse du lien ou de l'image, enregistrer l'image ou la page, etc.

Vidéos

Les vidéos YouTube (et Facebook, si vous vous y êtes connecté au moins une fois dans Courrier Adrien) se lisent dans le logiciel, avec reprise à l'endroit où vous vous étiez arrêté. Espace : lecture / pause.

Téléchargements

Les téléchargements s'affichent dans la barre du bas : progression, pause, arrêt et annulation. Cliquez sur l'icône de dossier pour choisir où ils sont enregistrés.

18. RSS to Email

Recevez les nouveaux articles de vos sites préférés sous forme de mails, dans le compte de votre choix.

  1. Cliquez sur RSS to Email.
  2. Saisissez l'adresse d'un site, puis cliquez sur Rechercher : Courrier Adrien trouve son flux RSS.
  3. Si le site n'a pas de flux, Créer un flux pour cette page en fabrique un, si c'est possible.
  4. Choisissez le compte de destination et cliquez sur Ajouter.

Autres boutons : Vérifier maintenant, Récupérer d'anciens articles, Copier l'adresse, Renommer (F2), ▲ Monter / ▼ Descendre et Supprimer.

19. TODO (rappels)

Bouton TODO. Saisissez le texte du rappel, la date et l'heure (format libre : 9.20, 9:20 ou 22.30), puis cliquez sur Ajouter. Vous pouvez choisir un son (bouton Fichier, et ▶ pour l'écouter).

À l'heure prévue, une fenêtre s'affiche avec le son. Cliquez sur OK, ou sur Reporter : dans 10 minutes, 30 minutes, 1 heure, demain à la même heure, dans une semaine, ou à une heure précise.

20. MAILING

Le bouton MAILING ouvre un logiciel d'envoi groupé (newsletters, annonces). Chaque destinataire reçoit son propre mail. La liste peut venir d'un dossier du carnet d'adresses, d'un fichier CSV ou d'un fichier Excel.

Conseil : c'est vous qui déterminez la fréquence d'envoi (par exemple, 1 mail toutes les 30 secondes). Renseignez-vous auprès de votre fournisseur de messagerie sur les fréquences qu'il autorise. Les hébergeurs surveillent les envois en nombre : gardez un rythme raisonnable, et envoyez de préférence depuis votre connexion habituelle : un envoi en masse depuis une connexion inconnue (4G, chez un ami…) peut être bloqué par l'hébergeur.

21. Relier votre téléphone à Courrier Adrien

Ce chapitre est un peu plus dense que les autres car nous avons tenu à vous expliquer au mieux tout le fonctionnement de cette liaison très pratique au quotidien. C'est dense et un peu long mais ne vous inquiétez pas ce n'est pas très compliqué.

TÉL affiche l'écran de votre téléphone sur le PC ; vous pouvez le piloter à la souris. Une fois le téléphone relié, vous pouvez aussi envoyer des SMS (section 22).

Android uniquement. Les iPhone ne sont pas compatibles, car Apple ne permet pas à un PC de piloter un iPhone.

Relier le téléphone à l'ordinateur (une seule fois)

Il suffit de cliquer sur TÉL. Si aucun téléphone n'est encore associé, Courrier Adrien l'explique et propose Associer un téléphone… : un assistant vous guide pas à pas, sans câble et sans ligne de commande (Android 11 et plus).

  1. Faire apparaître les « Options de développement » : sur le téléphone, Paramètres › À propos du téléphone › Informations sur le logiciel, puis touchez 7 fois de suite « Numéro de version ». Le message « Mode développeur activé » apparaît.
    Pas trouvé ? Le chemin change selon la marque : dans les Paramètres, touchez la loupe et tapez version (« Numéro de build » sur Pixel, « Version MIUI » ou « Version de HyperOS » sur Xiaomi).
  2. Activer le Débogage sans fil : le téléphone doit être sur le même Wi-Fi que l'ordinateur. Paramètres › Options de développement (tout en bas) › Débogage sans fil › activez l'interrupteur, cochez « Toujours autoriser sur ce réseau », puis touchez Autoriser.
  3. Scanner le QR code : touchez le texte « Débogage sans fil » (pas l'interrupteur) › Associer l'appareil avec un code QR, et visez le QR code affiché par Courrier Adrien. C'est tout : l'association se fait toute seule, puis l'écran du téléphone s'ouvre sur l'ordinateur.
    Le téléphone n'arrive pas à scanner ? Choisissez « Associer l'appareil avec un code d'association » et tapez dans l'assistant le code à 6 chiffres affiché par le téléphone.

Ensuite, un clic sur TÉL suffit, tant que le Débogage sans fil est activé et que l'ordinateur et le téléphone sont sur le même Wi-Fi. Courrier Adrien retient aussi le nom de votre téléphone et les Wi-Fi où il a été relié (maison, bureau…).

L'oubli au bout de 7 jours

Vous avez le choix de désactiver l'oubli automatique de l'autorisation, qu'Android applique normalement au bout de 7 jours sans connexion. Le choix se fait dans l'assistant d'association, avec la case « Ne pas oublier cet ordinateur au bout de 7 jours » :

  • Si vous cochez la case, tout sera désormais automatique.
  • Si vous ne la cochez pas, un rappel vous le signalera le 6e jour. Il suffit alors de cliquer sur Relier maintenant (Débogage sans fil activé, même Wi-Fi que l'ordinateur) : Android repart pour 7 jours.
  • Si l'association est perdue au bout du 7e jour, il faudra vous réassocier : un clic sur TÉL propose alors de rescanner le QR code.

Ne cochez pas la case si cet ordinateur n'est pas le vôtre ou s'il est partagé. Pour retirer l'accès plus tard, sur le téléphone : Débogage sans fil › Appareils associés › Oublier. Faites-le aussi avant de vendre, donner ou faire réparer cet ordinateur.

Android 10 ou plus ancien : le débogage sans fil n'existe pas. Activez le Débogage USB dans les Options de développement, branchez le téléphone et touchez Autoriser sur son écran.

Si le téléphone n'est pas trouvé

Courrier Adrien affiche une fenêtre qui explique la cause probable et continue de chercher le téléphone pendant 5 minutes : inutile de cliquer sur Réessayer, la connexion se fait toute seule dès qu'il est prêt.

  • Le Débogage sans fil s'est coupé (le cas le plus fréquent) : Android le fait après un redémarrage ou un changement de Wi-Fi. Rallumez-le : faites glisser le haut de l'écran vers le bas et touchez la vignette « Débogage sans fil », ou passez par Paramètres › Options de développement.
  • L'ordinateur est sur un Wi-Fi où le téléphone n'a jamais été relié : connectez le téléphone à ce même réseau, puis activez le Débogage sans fil en cochant « Toujours autoriser sur ce réseau ». Inutile de refaire l'association.
  • Le téléphone ne reconnaît plus l'ordinateur : c'est ce qui arrive quand les Options de développement ont été coupées (certaines applis de banque l'exigent), car Android efface alors l'association. Cliquez sur Rescanner le QR code : 30 secondes suffisent.
  • Téléphone branché en USB mais pas autorisé : touchez Autoriser sur son écran, en cochant « Toujours autoriser depuis cet ordinateur ».
Astuce, fortement conseillée : ajoutez la vignette du Débogage sans fil au volet rapide, pour le rallumer d'un geste. Options de développement › Vignettes de développeur (ou Mosaïques développeur raccourcis) pour paramètres rapides › activez Débogage sans fil.

Rallumage automatique du Débogage sans fil (facultatif)

Pour ne plus avoir à le rallumer à la main, Courrier Adrien vous propose, après une première connexion réussie, de le faire rallumer tout seul quand le téléphone revient sur un Wi-Fi. Il s'appuie pour cela sur Automate, une appli gratuite et sans limite de durée (éditeur LlamaLab, Play Store). Une fenêtre vous guide en trois étapes, chacune avec son bouton :

  1. Installer Automate : le Play Store s'ouvre sur le téléphone. Vérifiez que l'éditeur est LlamaLab, puis touchez Installer.
  2. Donner l'autorisation de rallumer le Débogage sans fil. Elle ne peut être donnée que depuis l'ordinateur, et disparaît si Automate est désinstallé.
  3. Envoyer la règle au téléphone, puis suivre les consignes affichées. Dans Automate, touchez IMPORT puis START, acceptez les autorisations proposées (touchez NEVER pour la position : la règle n'en a pas besoin), et cochez Run on system startup dans les Settings d'Automate pour qu'elle reparte après un redémarrage.

Pourquoi c'est sûr :

  • hors de chez vous, le Débogage sans fil reste coupé, comme Android le prévoit ;
  • il ne se rallume sans rien demander que sur les Wi-Fi marqués « Toujours autoriser sur ce réseau ». Ailleurs, Android vous demande la permission, une seule fois par connexion ;
  • il ne se rallume jamais quand les Options de développement sont coupées ;
  • la règle ne fait rien d'autre, et n'a besoin ni de votre position, ni de vos contacts, ni de vos messages. Tout se défait en désinstallant Automate.

Vous pouvez aussi choisir Plus tard (Courrier Adrien le reproposera le lendemain), Ne plus proposer, ou C'est déjà en place.

Les réglages du téléphone : la roue dentée ⚙

La petite roue dentée ⚙, à droite de TÉL, ouvre un menu :

  • Afficher l'écran du téléphone : comme un clic sur TÉL.
  • Réglages, pour changer d'avis à tout moment : associer un téléphone (ou rescanner le QR code), régler le rallumage automatique, régler le mode modem Wi-Fi, et la case « Proposer d'afficher le téléphone quand il est sur le même Wi-Fi » (voir ci-dessous).

Proposition d'afficher le téléphone : quand le téléphone est sur le même Wi-Fi que l'ordinateur (Débogage sans fil allumé), Courrier Adrien vous propose d'afficher son écran : Afficher l'écran, Pas maintenant ou Ne plus demander. Il ne l'affiche jamais de lui-même. La proposition arrive au lancement de Courrier Adrien (comptez une trentaine de secondes), puis à chaque retour du téléphone quand la liaison a été coupée par son départ ; jamais si l'écran du téléphone est déjà affiché. Après « Pas maintenant », Courrier Adrien ne redemande plus jusqu'à son prochain lancement : cliquez sur TÉL si vous changez d'avis. Après « Ne plus demander », vous pouvez changer d'avis à tout moment en recochant la case dans ⚙ › Réglages.

Aucune liaison sans votre accord : Courrier Adrien ne relie l'ordinateur au téléphone qu'après une validation de votre part (TÉL, Afficher l'écran, SMS…). Pour savoir si le téléphone est là, il se contente d'écouter le Wi-Fi, sans s'y connecter. La liaison est coupée quand le téléphone s'en va (environ une minute après, sauf si son écran est affiché ou si un envoi de SMS est en cours) et à la fermeture de Courrier Adrien.

Pendant la recherche du téléphone, une petite fenêtre avec une barre de progression indique l'étape en cours ; elle se ferme dès que l'écran du téléphone apparaît.

Protéger le téléphone par un code (facultatif, conseillé)

Nous vous conseillons d'activer le code de protection du téléphone dans Courrier Adrien, surtout si vous utilisez votre ordinateur dans un lieu public.

Comment ça marche ? Si vous vous éloignez de votre ordinateur sans avoir activé le code et que vous restez dans la zone Wi-Fi de l'ordinateur avec votre téléphone, quelqu'un de mal intentionné pourrait utiliser votre ordinateur pour voir ce que vous faites sur votre téléphone, ou envoyer des SMS à votre place. Avec le code, c'est impossible : pensez seulement à fermer la fenêtre du téléphone avant de vous éloigner, car le code est demandé à son ouverture.

Courrier Adrien vous propose ce code (propre à Courrier Adrien) après une première connexion : Activer la protection ou Ne plus demander (vous pourrez l'activer plus tard dans ⚙ › Réglages).

  • Le code est demandé chaque fois que vous voulez ouvrir la fenêtre du téléphone (TÉL, Afficher l'écran, SMS). Il n'est pas demandé si cette fenêtre est déjà ouverte : fermez-la avant de vous absenter.
  • Activer, changer ou désactiver la protection à tout moment : ⚙ › Réglages › Protection par code.
  • Code oublié ? Il faut rescanner le QR code avec le téléphone (preuve que vous l'avez en main), puis choisir un nouveau code.
  • Alerte sur le téléphone : tant que son écran est affiché sur l'ordinateur, une notification « Courrier Adrien — L'écran de ce téléphone est affiché sur l'ordinateur » est présente dans le volet de notifications du téléphone (rangée sous « Shell »). Elle disparaît quand l'écran est fermé sur l'ordinateur. Si vous la voyez alors que vous n'êtes pas devant votre ordinateur, quelqu'un regarde votre téléphone. Désactivable dans ⚙ › Réglages.

Quand le téléphone sert de modem (partage de connexion)

  • Partage de connexion par câble USB : rien de particulier, le câble suffit. Activez le Débogage USB dans les Options de développement et touchez Autoriser sur le téléphone la première fois. Utilisez de préférence un câble USB-A vers USB-C (prise rectangulaire classique côté ordinateur) : avec certains ordinateurs, un câble USB-C vers USB-C ne permet ni la charge ni le partage de connexion.
  • Point d'accès Wi-Fi : dans ce mode, Android coupe le Débogage sans fil (le téléphone n'est connecté à aucun Wi-Fi : c'est lui qui le diffuse). Courrier Adrien peut alors utiliser une autre liaison d'Android, s'il l'a mise en place auparavant. Cochez la case dans ⚙ › Réglage du mode modem Wi-Fi (elle vous est aussi proposée une fois, après une connexion réussie).

Avec cette option :

  • en point d'accès, un clic sur TÉL trouve le téléphone tout seul, sans câble ;
  • quand l'ordinateur se connecte au point d'accès du téléphone (ou au lancement de Courrier Adrien s'il y est déjà connecté), Courrier Adrien propose d'afficher l'écran du téléphone (Afficher l'écran / Pas maintenant). Comptez une trentaine de secondes avant que cette proposition apparaisse : Courrier Adrien vérifie toutes les 30 secondes. Elle n'est faite qu'une fois par connexion au point d'accès, et pas si l'écran du téléphone est déjà affiché ;
  • la liaison se met en place lors d'une connexion normale (Wi-Fi de la maison ou câble USB), et reste possible jusqu'au prochain redémarrage du téléphone ou à la prochaine relance de son Débogage sans fil (par exemple au retour sur le Wi-Fi de la maison) ; elle est alors refaite en passant, la prochaine fois que vous affichez l'écran du téléphone à la maison ;
  • après un redémarrage du téléphone, la liaison est rétablie à la connexion suivante (clic sur TÉL à la maison). Si le téléphone a redémarré pendant que vous étiez dehors, en point d'accès, Courrier Adrien vous demande de le brancher une fois avec son câble USB : Android ne permet pas de rétablir la liaison autrement. Branchez-le : Courrier Adrien le détecte aussitôt, propose de rétablir la liaison, puis affiche l'écran du téléphone. Vous pouvez ensuite débrancher le câble.
    Pourquoi le câble est obligatoire dans ce cas : c'est une mesure de sécurité d'Android. Le point d'accès Wi-Fi relie bien l'ordinateur au téléphone, mais seulement pour Internet : après un redémarrage, Android n'accepte plus aucune commande par le Wi-Fi tant que vous n'avez pas fait un geste physique sur le téléphone (le brancher). Sinon, n'importe quel ordinateur connecté à votre point d'accès (une connexion prêtée dans un train, par exemple) pourrait tenter de piloter votre téléphone. Le câble ne sert qu'une fois par redémarrage, et uniquement si le téléphone n'est pas repassé par le Wi-Fi de la maison entre-temps.

Pour que cela fonctionne, laissez le Débogage USB activé dans les Options de développement : sans lui, Android arrête tout le débogage quand il coupe le Débogage sans fil, et la liaison se ferme.

Bon à savoir : une fois en place, la possibilité de liaison reste active jusqu'au prochain redémarrage du téléphone ou à la prochaine relance de son Débogage sans fil, mais seuls les ordinateurs que vous avez déjà autorisés peuvent l'utiliser : toute tentative d'intrusion afficherait une demande d'autorisation sur votre téléphone, il suffirait de toucher « Refuser ». Si vous voulez néanmoins couper la liaison manuellement, allez dans ⚙ › Réglage du mode modem Wi-Fi › Couper la liaison maintenant, ou décochez Débogage USB dans les Options de développement, ou redémarrez votre téléphone.

22. Utilisation des SMS

SMS envoie des SMS par votre téléphone, avec votre forfait, un par un. Le téléphone doit d'abord être relié à Courrier Adrien (section 21).

  • Choisissez les destinataires : dans le carnet (dossier entier ou contacts sélectionnés), ou depuis un fichier CSV ou Excel. Vous pouvez joindre des photos.
  • Réglez l'intervalle entre deux SMS (20 secondes minimum). Les opérateurs bloquent une ligne qui envoie en rafale, c'est pourquoi Courrier Adrien est réglé par défaut sur 30 secondes (45 secondes quand des photos sont jointes, car les MMS sont plus lents).
  • LANCER L'ENVOI, puis PAUSE, ARRÊTER si besoin.
  • Laissez le téléphone allumé et déverrouillé pendant l'envoi. S'il se verrouille ou si un envoi échoue, l'envoi se met en pause sans sauter de destinataire. Déverrouillez, puis cliquez sur REPRENDRE. Après une fermeture de la fenêtre, REPRENDRE repart au bon endroit, avec la même liste et le même message. ABANDONNER oublie l'envoi interrompu.
  • Au-delà d'environ 30 SMS en 30 minutes, Android demande normalement une confirmation. Courrier Adrien relève ce seuil pendant l'envoi, puis le remet comme avant.

L'envoi automatique a été testé avec l'application Messages de Samsung. Avec une autre application SMS ou un téléphone double SIM, il peut ne pas trouver le bouton Envoyer : rien n'est alors envoyé et l'envoi se met en pause.

23. Sons

Le bouton SONS attribue un son de réception à chaque compte (Fichier pour le choisir, ▶ Lire pour l'écouter, puis Enregistrer). Vous savez ainsi, sans regarder, quel compte vient de recevoir un mail.

24. CONTRÔLE et CONSOLE

CONTRÔLE montre ce que fait le logiciel, compte par compte : relèves en cours et à venir, nombre de mails et de dossiers, images qui n'ont pas pu être téléchargées. La liste de ces images peut être nettoyée (Supprimer la sélection, ou touche Suppr).

CONSOLE affiche le journal technique en direct. Il est utile pour comprendre un problème ou le signaler.

26. Vos données, désinstallation

Tout est stocké uniquement sur votre PC, dans le dossier suivant :

%LOCALAPPDATA%\COURRIER

Collez ce chemin dans la barre d'adresse de l'Explorateur Windows pour l'ouvrir. Il contient vos comptes, vos mails, vos modèles, vos macros, le carnet d'adresses, les sons et vos réglages.

  • Sauvegarde : copiez ce dossier.
  • Désinstallation : supprimez le dossier décompressé, puis le dossier %LOCALAPPDATA%\COURRIER. Aucune clé de registre n'est créée lors d'un lancement normal.

27. Mises à jour

Courrier Adrien se met à jour tout seul. Vous n'avez rien à télécharger vous-même.

  1. Une vingtaine de secondes après le démarrage, il vérifie s'il existe une version plus récente.
  2. Si c'est le cas, une fenêtre « Mise à jour disponible » affiche votre version et la nouvelle, avec trois choix :
    • Installer maintenant : la mise à jour est téléchargée (barre de progression, bouton Annuler possible) ;
    • Plus tard : elle vous sera proposée au prochain démarrage ;
    • Ignorer cette version : elle ne vous sera plus proposée. La suivante le sera.
  3. Une fois le téléchargement terminé, Courrier Adrien se ferme normalement, installe la nouvelle version, puis redémarre tout seul. Une petite fenêtre « Installation de la mise à jour… » vous fait patienter quelques secondes.
  4. Au redémarrage, un message confirme la mise à jour et la date de la nouvelle version.

Si d'autres fenêtres de Courrier Adrien sont ouvertes, par exemple un mail en cours de rédaction, il ne les ferme pas d'office : il vous les liste. Choisissez Je les ferme (il proposera de redémarrer dès qu'elles seront fermées) ou À la fermeture de COURRIER ADRIEN (la mise à jour s'installera quand vous quitterez le logiciel).

Vos comptes, vos mails et vos réglages sont conservés. Seul le programme est remplacé ; le dossier %LOCALAPPDATA%\COURRIER n'est jamais touché. Le mode d'emploi, lui, est mis à jour en même temps.
  • Emplacement : pour que la mise à jour automatique fonctionne, placez Courrier Adrien dans un dossier où vous pouvez écrire (Bureau, Documents…), pas dans « Program Files ». Sinon, il vous le signale et ouvre la page de téléchargement.
  • En cas d'échec (téléchargement interrompu, fichiers bloqués par un antivirus…), rien n'est modifié : l'ancienne version reste en place, et la mise à jour vous sera proposée à nouveau au prochain démarrage. Vous pouvez aussi la télécharger à la main sur la page des versions de Courrier Adrien, indiquée dans le message.

28. En cas de problème

  • Un mail s'affiche mal : cliquez sur RECHARGER dans son bandeau.
  • Un compte ne reçoit plus : cliquez sur le petit rond gris devant son nom, puis regardez CONTRÔLE.
  • Un site ne s'affiche pas : utilisez INTERNET ou le bouton « Page bloquée ».

Pour signaler un bug, écrivez à adrienmel@gmail.com en joignant si possible les fichiers journal.txt, crash_traceback.txt et crash_natif.txt, ainsi que le dossier Logs, tous situés dans %LOCALAPPDATA%\COURRIER.
